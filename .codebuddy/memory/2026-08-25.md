## 远程编译 tds（192.168.2.250，麒麟 V10 桌面 x86_64）

- 主机：银河麒麟桌面操作系统 V10 SP1，x86_64，8 核 7.2G 内存，SSH 用户 JHD。
- 桌面路径经 `xdg-user-dir DESKTOP` 获取（PowerShell 传中文参数给远程 shell 会编码损坏，尽量用英文命令+脚本文件）。
- 代码从 Gitee `gitee.com/liangtuSoft/tds.git` clone 到 `~/桌面/tds-build`，`bash build.sh x86_64` 编译，产物 `~/桌面/tds-build/out/tds/tds`（7.7M，ELF x86-64）。
- 注意：主机上已有 tds 实例在运行（占用 60006 端口），新版 tds 启动会提示 already running 自动退出；`licence invalid, io server stopped` 是授权问题，非编译问题。
- Posh-SSH 用 `Invoke-SSHCommand` 时，后台进程需 `setsid bash -c "nohup ... < /dev/null &"` 并立即返回，否则 SSH 通道挂起超时；awk/复杂引号脚本先写到本地文件再 Set-SCPItem 上传执行，避免 PowerShell 转义问题。

## 修复 quickjs 链接 bug（commit 82f866b8，已 push）

- 远程 7c57db09 把 `__js_infinity`/`__js_nan` 内联函数定义放在 `#ifdef _MSC_VER` 内，但调用点无平台保护，Linux(gcc) 链接报 `undefined reference to '__js_infinity'/'__js_nan'`。
- 修复：两个函数定义为无条件提供（移出 _MSC_VER 分支），`JS_FLOAT64_NAN` 保持平台分支（_MSC_VER 用 `__js_nan()`，其余用 `NAN`）。

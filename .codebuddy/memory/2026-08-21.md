# 2026-08-21

## 修复 quickjs.c 在 MSVC 新 SDK 下的编译错误

另一台电脑用 VS2019(v142) 编译 `src/script/quickjs.c` 时报 C2099（初始值设定项不是常量）、C0059（除数为零）等错误。根因是新版 Windows SDK 的 UCRT 在 C 模式下可能把 `NAN` 定义成 `__builtin_nanf("0")` 函数调用，不能用于 `static const` 数组初始化；同时 `1.0 / 0.0` 在静态初始化中也会触发除零错误。

已在 `src/script/quickjs.c` 中：
- 在 `#include <math.h>` 后针对 `_MSC_VER` 定义 `JS_CONST_INFINITY` 与 `JS_CONST_NAN`；
- 将 `js_number_funcs` 和 `js_global_funcs` 中的 `NAN`、`INFINITY`、`1.0/0.0` 静态初始化替换为上述常量宏。

非 MSVC 平台保持原 `INFINITY` / `NAN` 宏，Linux 编译行为不变。

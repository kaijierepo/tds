- **CSeq 答案**：应一条 RTSP 信令连接一个计数器。原实现是进程级 static 全局计数器（不规范）。改为 `Connection::cseq_` + `nextCSeq()`（streamSession.h），7 个 rtsp* 调用点零签名改动（都有 conn 参数）
- **setState → STREAM_SESSION 成员**：按用户要求去掉 status_callback_ 通知和 cv_.notify_all()，仅保留 `state_ = new_state`
  - 连锁清理：StatusCallback 别名、setStatusCallback 方法、status_callback_ 成员、cv_ 成员（全库无人 wait）、streamServer.cpp 中的注册（仅 LOG）
  - 原 setState 硬编码写 session_origin_pull_.state_，迁移后调用点全部显式写 session_origin_pull_.setState()（推流重连处也保持写 origin_pull，与原行为一致）
- **shouldReconnect/doReconnect → STREAM_SESSION 成员**（实现于 streamSession.cpp）
  - doReconnect 成员只含 retry_count_++/时间更新/退避 sleep；stats_.reconnect_count++ 和 setState(RECONNECTING) 留在 controlThread 两个调用点
  - 注意：shouldReconnect 此前就无调用方（max_retries_ 上限未生效），本次仅迁移未改变该行为
- **setError 保留在 StreamNode**（仍含 stats_.errors++、error_callback_，setState 改调成员）
- state_mutex_ 保留（getState 仍在用）
- 另：streamNode_rtsp.cpp 981-982 两处重复 HANDSHAKING setState 合并为一处（msg 随回调删除后已相同）

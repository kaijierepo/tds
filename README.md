# TDS - 物联网数据服务

   用户手册与二次开发文档 https://tdserver.org

## 最轻便的物联网组态软件

* **轻量通用**: 小微物联系统通用监控软件，数据采集，存储，可视化，统计分析。

* **组态化**: 组织结构与监控点变量组态，设备IO通信组态，基于SVG的监控画面组态。

* **多协议集成**: HTTP-API，Websocket，MQTT，原始TCP/UDP

* **极简部署**: 小于6mb运行文件，无任何第三方库依赖，解压运行

* **协议支持**：Modbus-RTU、Modbus-TCP、BacNet、DL/T645、Onvif、RTSP、OPC-UA、EtherNet/IP、SNMP
    

## 内置时序数据库

* 无需安装第三方数据库，内置时序数据库引擎

* 完全列式存储，支持高并发实时数据与历史数据读写

* 基于HTTP API的数据库增删改查接口

* 支持多种条件查询、数据聚合查询、统计分析查询

* 基于JSON的文件数据库，支持复杂数据结构存储

## 内置JS引擎

* **设备脚本**：通过脚本进行设备协议解析、通信，快速接入各类非标二进制设备协议

* **分析脚本**：对采集实时数据、历史数据应用自定义脚本分析算法

* **控制脚本**： 基于监控点数据设置各类控制逻辑、计划任务

* **表达式脚本**：通过js表达式添加系统二次计算变量

## 内置流媒体服务器

* 自研轻量级流媒体引擎，无第三方流媒体框架依赖

* **RTSP 完整协议栈**：支持拉流（从摄像头取流）、推流（向远端转发），兼容 UDP/TCP 双传输模式，支持 RTSP Digest/Basic 认证

* **WebRTC 低延迟分发**：浏览器端子秒级延迟（< 500ms），无需插件即可实时观看；基于 mbedtls 实现 DTLS-SRTP 端到端加密

* **录像存储**：支持 H.264 流实时录制为 MP4，按时间范围回放

* **自动节能**：无客户端观看时自动断开拉流连接，节省设备与带宽资源

* **本地文件流化**：将本地视频文件直接转为 RTSP 流对外服务

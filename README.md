# TDS - 物联网数据服务

   用户手册与二次开发文档 https://tdserver.org

## 最轻便的物联网组态软件

   小微物联系统通用监控软件。
   支持Modbus-RTU、Modbus-TCP、BacNet、DL/T645、Onvif、RTSP、OPC-UA、EtherNet/IP、SNMP协议接入。
   HTTP-API服务接口，易于第三方集成。
   组态化构建IO通信与监控界面，基于SVG的拓扑画面组态。
   小于6mb运行文件，无任何第三方库依赖，解压运行，极简部署。

## 内置基于JSON文件的时序数据库
   
   无需安装第三方数据库，内置时序数据库引擎，支持高并发实时数据与历史数据读写。
   基于HTTP API的数据库增删改查接口，支持多种条件查询、数据聚合查询、统计分析查询。

## 内置JavaScrip脚本引擎

   物联网组态软件界的nodejs。你可以：
   1.通过脚本进行设备协议自定义解析、通信
   2.对采集实时数据、历史数据应用自定义脚本分析算法 
   3.基于监控点数据设置各类控制逻辑、计划任务
